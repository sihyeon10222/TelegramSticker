- 팩 128MiB·GIF 8MiB 제품 제한 제거. 파일 다운로드·파일 GIF 인코딩·Worker 스트리밍 사용. 형식·픽셀·프레임·경로 검증과 Telegram 일반 다운로드 20MiB 경계는 유지한다.
- 실패 항목에 단계·원인·재시도 여부 표시. 일시적 요청 오류와 변환 자원 문제를 구분한다. 변환 품질 조절은 길이를 보존하며 앱에 표시한다.
- 캐시 삭제는 설치된 이미지·GIF·재생용 파일·팩 순서·최근 사용·연결 설정을 유지한다. 작업 중에는 비활성화한다.
- Telegram 팩 업데이트는 새 조회 결과의 추가·삭제·순서를 반영한다. 파일 준비 실패 시 기존 revision을 유지하며 삭제된 팩을 되살리지 않는다.
- 앱 상세의 스티커 탭은 큰 미리보기만 연다. 복사·공유는 별도 버튼이다. 키보드는 탭 즉시 복사를 유지한다.
- 키보드는 작은 재생용 GIF와 제한된 프레임 캐시를 사용한다. 화면 밖 셀·숨겨진 페이지는 재생하지 않는다. 동작 줄이기와 메모리 경고 시 정적 표시를 사용한다.
- **스크롤 중 일괄 정지는 사용자 요청에 따라 제거했다.** 보이는 GIF는 수직 스크롤·관성 스크롤·좌우 팩 드래그 중에도 재생한다. 공통 run-loop 모드의 재생 시계를 유지한다.
- iPhone 세로 기본 크기에서 7열·4행, 전체 목록은 팩마다 새 줄, 좌우 전환은 손가락 이동에 따른다. 좁은 창·접근성 크기에서는 열 수를 조정한다.
