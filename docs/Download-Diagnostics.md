# 다운로드 실패 진단 (2026-10-15)

개발자 로그는 HTTP 상태, 선택한 응답 헤더, 실제/선언 바이트 수, 전체 스티커 ID,
형식/크기, 입력 파일 magic 16바이트, 단계별 오류 코드, NSError 원본/underlying 코드,
변환 품질, 재시도 횟수, 경과 시간을 기록한다. 인증 헤더/원본 Telegram URL/응답 본문은
기록하지 않으며 Bearer/Bot 토큰 패턴을 마스킹한다. 실패 저장 JSON에 optional
technicalDetails를 추가해 기존 데이터는 계속 읽는다.

크기/디코딩 제한은 ImportLimitFailure의 check/actual/limit로 구분한다. 결정적인 제한 초과는
동일한 파일을 여섯 번 다운로드하지 않고 중단한다. 로그 화면은 ‘선택/완료’와 ‘비우기’를
제공하고 선택 모드에서 전체 선택/해제 및 선택 로그 복사를 제공한다.
